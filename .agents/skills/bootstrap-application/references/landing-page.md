# Landing page profile

Build the requested marketing sections and accessible header/footer. Set title, description,
canonical URL, OpenGraph/Twitter metadata, favicon, and responsive imagery for the real brand.
Add `robots.txt` and a sitemap for actual public routes; choose indexability from the launch
plan. Check keyboard navigation, semantic headings, image alt text, mobile layout, and performance.
Add analytics only if requested, with a deliberate privacy/cookie policy.

Use server functions only for real actions such as a validated contact or signup form. Decide
where submissions go and how abuse is limited before exposing a form. A static landing page
does not need a database, auth, Query provider, or dashboard shell.
